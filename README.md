# Sign99RTS

An RTS space-battles game, lightly inspired by *Gate 88*, the 2005 RTS by Jonathan Mak.

Built as a modern web and desktop app: single-player skirmishes against AI, plus LAN and online multiplayer for up to 8 players on shared or opposing teams. Built with Vite and TypeScript, packaged for the browser and for the desktop via Electron.

## Getting started

```bash
npm install
npm run dev        # browser dev server
npm run desktop    # build and launch the Electron app
```
