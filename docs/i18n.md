# Localization (i18n)

Sign99RTS renders its UI to a `<canvas>` that redraws every frame, so localization
is deliberately minimal: [`src/i18n.ts`](../src/i18n.ts) holds a flat key → string
table per locale and a `t(key, params?)` lookup. Because every frame re-reads the
strings, switching language takes effect immediately — there is no re-render hook.

## Supported locales

`en` (source), `es`, `fr`, `de`, `pt-BR`, `it`, `ru`, `ja`, `zh-CN`.

Initial locale = saved choice (`localStorage['sign99_locale']`) → best match from
`navigator.languages` → `en`. Players change it in **Settings → Language**.

## Using it

```ts
import { t } from './i18n.js';              // or `import { t as tr }` where a
ctx.fillText(t('settings.heading'), x, y);  // local `t` variable already exists
ctx.fillText(t('hud.buildingsUnpowered', { count: n }), x, y);  // {count} placeholder
```

Fallback chain per key: active locale → English → the key string itself.

## Fonts

The bundled display faces (Poiret One, BJ Cree) are Latin-only. Every canvas
`font` string now ends with a system fallback chain (Noto Sans / Noto Sans CJK /
Microsoft YaHei / PingFang / Hiragino / Yu Gothic / Meiryo / Segoe UI) so
Cyrillic and CJK text renders using whatever the player's OS provides. Latin
text is unaffected because the display face is still listed first.

## Translation status

**The non-English strings are machine translations pending human review.**
English is the source of truth — add new keys to the `en` table first, then to
each locale. A missing key in a locale simply falls back to English.

## Converted so far

- Title screen, Play menu, LAN-type menu, Pause menu
- Settings screen (all rows + font note + Discord button)
- Practice setup (all row labels + buttons)
- Vs. AI / Survival setup (headers, shared row labels, buttons, rank/score labels)
- Enum labels: graphics quality, research unlock, victory/defeat conditions
- HUD: ENERGY / HP / SHIELD / RESEARCH, income readout, unpowered-building warning
- Tutorial: every step message
- Overlays: "Loss.", "COMMAND MODE"

## Not yet converted (English literals remain, safe fallback)

- LAN / Online lobby screens (`drawLanHostLobby`, `drawLanClientLobby`,
  `drawLanBrowser`, `drawLanJoin`, `drawOnline*`) — status strings, table
  headers, connection errors
- A few Vs. AI setup extras: "AI APM (-1 = derived)", "Ranked score multiplier"
- AI chatter routed through `HUD.showAIChat` (enemyai.ts, vsaibot.ts, …) — this
  is dynamic flavor narration; extract to keys when prioritized
- `actionmenu.ts` build/research palette entries (building names come from
  `builddefs.ts`)

To extend: add keys to `src/i18n.ts`, then replace the literal in the draw code
with `t('your.key')`.
